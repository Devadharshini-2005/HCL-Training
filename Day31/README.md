# Day 31 – Student Marks Calculator using Angular Signals

## Project Overview

The Student Marks Calculator is an Angular application developed to understand and practice Angular Signals, Computed Signals, and Effects.

It allows users to enter student marks and automatically calculates the total, average, and result using Angular's reactive state management.

## Technologies Used

- Angular
- TypeScript
- HTML
- CSS

## Concepts Covered

### 1. Signals
- Creating signals using `signal()`
- Reading signal values
- Updating values using `set()` and `update()`

### 2. Computed Signals
- Creating derived values using `computed()`
- Automatically calculating total marks
- Calculating average marks
- Displaying the result based on marks

### 3. Effects
- Creating effects using `effect()`
- Tracking signal changes
- Performing side effects when signal values change

## Features

- Enter marks for Mathematics, Science, and Computer Science.
- Automatically calculate total marks.
- Automatically calculate average marks.
- Display the student's result.
- Reset marks using the reset functionality.
- Update calculated values reactively whenever marks change.



## Learning Outcome

Understood how Angular Signals manage reactive state, how Computed Signals derive values from existing signals, and how Effects execute side effects when tracked signals change.
