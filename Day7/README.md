# Day 7 – Complaint Management API and Leave Management API

## Overview
Developed two backend applications, Complaint Management API and Leave Management API, using .NET as part of the HCL Training Program. The task focused on understanding Web API development and implementing basic backend operations.

## Technologies Used
- C#
- .NET
- ASP.NET Core Web API
- SQL Server

## Projects

### 1. Complaint Management API
Developed a RESTful API to manage complaints. The application handles complaint-related operations such as creating, viewing, updating, and managing complaint details.

### 2. Leave Management API
Developed a RESTful API to manage employee leave requests. The application handles leave-related information and basic leave management operations.

## Concepts Covered
- Introduction to ASP.NET Core Web API
- RESTful API principles
- Controllers and HTTP methods
- GET, POST, PUT and DELETE operations
- Model creation
- Routing
- Request and response handling
- CRUD operations
- Database connectivity

## Learning Outcomes
- Understood the fundamentals of .NET Web API development.
- Learned how to create API controllers and endpoints.
- Practiced implementing CRUD operations.
- Understood HTTP methods and status codes.
- Gained experience in developing backend applications.

## How to Run
1. Clone or download the repository.
2. Open the respective project folder in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the database connection if required.
5. Build and run the project.
6. Test the API endpoints using Swagger or a suitable API testing tool.
