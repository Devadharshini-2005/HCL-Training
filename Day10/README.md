# Day 10 – Delegates Practice in C#

## Overview
Practiced Delegates in C# as part of the HCL Training Program. The task focused on understanding how delegates work and how they can be used to reference and invoke methods.

## Technologies Used
- C#
- .NET Console Application

## Concepts Covered
- Introduction to Delegates
- Delegate Declaration
- Delegate Instantiation
- Delegate Invocation
- Single-Cast Delegates
- Multicast Delegates
- Passing Methods as Parameters
- Understanding Method References

## Description
Practiced delegate concepts through C# programs to understand how delegates store references to methods and allow methods to be called indirectly. Explored how delegates can be used to pass methods as arguments and execute multiple methods.

## Learning Outcomes
- Understood the concept of delegates in C#.
- Learned how to declare and use delegates.
- Practiced single-cast and multicast delegates.
- Understood how to pass methods as parameters.
- Learned the role of delegates in flexible and reusable programming.
