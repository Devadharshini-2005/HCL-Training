# Day 3 – BMI Calculator

## Overview
Developed a BMI (Body Mass Index) Calculator using HTML, CSS and JavaScript as part of the HCL Training Program. The application calculates BMI based on the user's height and weight and displays the corresponding BMI result.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Covered
- HTML forms and input fields
- CSS styling and layouts
- JavaScript variables and functions
- DOM manipulation
- Event handling
- Form input validation
- Mathematical calculations
- Conditional statements

## Project Description
Created an interactive BMI Calculator that allows users to enter their height and weight. JavaScript is used to calculate the BMI value and display the result along with the corresponding BMI category.

**BMI Formula:**

BMI = Weight (kg) / Height (m)²

## Learning Outcomes
- Learned how to handle user inputs using JavaScript.
- Practiced DOM manipulation and event handling.
- Understood how to perform calculations using JavaScript.
- Implemented basic input validation.
- Learned to display dynamic results on a webpage.

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in any web browser.
5. Enter height and weight to calculate BMI.
