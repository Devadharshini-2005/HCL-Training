# Day 11 – LINQ Practice in C#

## Overview
Practiced Language Integrated Query (LINQ) in C# as part of the HCL Training Program. The task focused on understanding how to query, filter, sort, and manipulate collections of data using LINQ.

## Technologies Used
- C#
- .NET Console Application
- LINQ

## Concepts Covered
- Introduction to LINQ
- LINQ Query Syntax
- LINQ Method Syntax
- Filtering using Where()
- Sorting using OrderBy() and OrderByDescending()
- Selecting data using Select()
- First() and FirstOrDefault()
- Single() and SingleOrDefault()
- Any() and All()
- Count(), Sum(), Average(), Min() and Max()
- GroupBy()
- ToList() and ToArray()

## Description
Practiced LINQ operations using C# programs to retrieve and manipulate data from collections. Explored different LINQ methods to filter, sort, select, group, and perform aggregate operations on data.

## Learning Outcomes
- Understood the fundamentals of LINQ.
- Learned the difference between query syntax and method syntax.
- Practiced filtering and sorting collections.
- Learned to retrieve specific records from data.
- Understood grouping and aggregate operations.
- Improved data manipulation and problem-solving skills.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio.
3. Build the project.
4. Run the console application.
