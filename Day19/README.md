# Day 19 – Library Management System

## Overview
Developed a Library Management System as part of the HCL Training Program. The project focuses on managing library-related information, including books and library operations, using .NET and Entity Framework Core.

## Technologies Used
- C#
- .NET
- Entity Framework Core
- SQL Server

## Concepts Covered
- ASP.NET Core / .NET Application Development
- Entity Framework Core
- DbContext and DbSet
- Entity Models
- Database Connectivity
- Code-First Approach
- Entity Framework Migrations
- CRUD Operations
- LINQ Queries
- Exception Handling

## Project Description
Created a Library Management System to manage book-related information. Practiced database operations using Entity Framework Core and implemented functionality to perform operations such as adding, viewing, updating, and deleting records.

## Learning Outcomes
- Understood the basic workflow of a Library Management System.
- Improved knowledge of Entity Framework Core.
- Learned how to connect .NET applications with SQL Server.
- Practiced database migrations and CRUD operations.
- Gained experience in managing application data using EF Core.
- Improved backend development skills.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the SQL Server connection string.
5. Apply database migrations if required.
6. Build and run the application.
