# Day 21 – Advanced Web API Practice

## Overview
Practiced advanced Web API concepts using ASP.NET Core as part of the HCL Training Program. The task focused on improving API development skills by exploring advanced backend concepts, application architecture, and database integration.

## Technologies Used
- C#
- .NET
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger

## Concepts Covered
- Advanced RESTful API Development
- API Controllers and Routing
- HTTP Methods and Status Codes
- Model Binding and Validation
- Data Transfer Objects (DTOs)
- Dependency Injection
- Repository Pattern
- Service Layer
- Entity Framework Core
- Asynchronous Programming
- CRUD Operations
- Exception Handling
- Swagger API Documentation

## Description
Practiced advanced ASP.NET Core Web API development by exploring structured application architecture and backend implementation. Focused on separating responsibilities using controllers, services, and repositories, handling data through Entity Framework Core, and implementing asynchronous operations.

## Learning Outcomes
- Improved understanding of ASP.NET Core Web API.
- Learned structured backend application development.
- Understood the use of DTOs.
- Practiced implementing dependency injection.
- Gained experience with repository and service patterns.
- Improved knowledge of Entity Framework Core.
- Practiced asynchronous API operations.
- Strengthened backend development skills.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the SQL Server connection string if required.
5. Apply database migrations if required.
6. Build and run the application.
7. Open Swagger to test the API endpoints.
