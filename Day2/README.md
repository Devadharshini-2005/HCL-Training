# Day 2 – Personal Portfolio Website

## Overview
Created a personal portfolio website using HTML and CSS as part of the HCL Training Program. The project focuses on presenting personal information, skills, education, and projects through a simple and well-structured website.

## Technologies Used
- HTML5
- CSS3

## Concepts Covered
- HTML page structure
- Navigation bar
- CSS styling and layouts
- Flexbox
- Colors, fonts and backgrounds
- Margin and padding
- Section alignment
- Portfolio webpage design

## Project Description
Developed a personal portfolio website to showcase profile information, technical skills, educational background, and projects. Used HTML to structure the content and CSS to design and style the different sections.

## Learning Outcomes
- Learned how to create a personal portfolio webpage.
- Improved HTML and CSS skills.
- Practiced designing and organizing multiple webpage sections.
- Understood navigation and layout design.
- Gained experience in creating user-friendly web pages.

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in any web browser.
