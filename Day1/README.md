# Day 1 – Web Page Clone

## Overview
Created a web page clone using HTML and CSS as part of the HCL Training Program. The task focused on understanding webpage structure and recreating a website layout using basic frontend technologies.

## Technologies Used
- HTML5
- CSS3

## Concepts Covered
- HTML page structure
- HTML elements and tags
- CSS styling
- Colors, fonts and backgrounds
- Margin and padding
- Layout and alignment
- Basic webpage design

## Project Description
Developed a webpage by recreating an existing website design using HTML and CSS. Practiced structuring webpage content and applying CSS styles to achieve the required layout and appearance.

## Learning Outcomes
- Understood the basic structure of HTML documents.
- Learned how to style web pages using CSS.
- Practiced positioning and aligning webpage elements.
- Improved understanding of frontend webpage development.

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in any web browser.
