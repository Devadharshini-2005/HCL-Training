# Day 4 – Grocery Website

## Overview
Developed a Grocery Website using HTML, CSS and JavaScript as part of the HCL Training Program. The project focuses on creating a user-friendly grocery shopping interface with interactive features.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Covered
- HTML structure and semantic elements
- CSS styling and layouts
- Flexbox and Grid
- JavaScript functions
- DOM manipulation
- Event handling
- Dynamic content updates
- User interaction

## Project Description
Created a grocery website to display grocery products in an organized layout. Used HTML to structure the webpage, CSS to design the interface, and JavaScript to add interactive functionality.

## Learning Outcomes
- Improved HTML and CSS design skills.
- Learned to create structured product layouts.
- Practiced JavaScript event handling.
- Understood DOM manipulation.
- Gained experience in developing interactive frontend applications.

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in any web browser.
