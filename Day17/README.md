# Day 17 – Flight Booking System and Student Course Management

## Overview
Developed two applications, Flight Booking System and Student Course Management, as part of the HCL Training Program. These tasks focused on implementing application logic, managing data, and understanding real-world management system workflows.

## Technologies Used
- C#
- .NET
- ADO.NET (if used in the Student Course Management project)

## Projects

### 1. Flight Booking System
Developed a Flight Booking System to manage flight-related information and booking operations. The application focuses on handling flight details and understanding the basic flight booking workflow.

### 2. Student Course Management
Developed a Student Course Management System to manage student and course-related information. The application focuses on organizing student details and course information.

## Concepts Covered
- C# Programming
- Object-Oriented Programming (OOP)
- Classes and Objects
- Properties and Methods
- Data Management
- CRUD Operations
- User Input Handling
- Application Workflow
- Basic Business Logic
- Database Connectivity 

## Learning Outcomes
- Understood the workflow of flight booking applications.

- Gained experience in implementing application logic.
- Improved problem-solving skills through practical tasks.
