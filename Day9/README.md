# Day 9 – Course Management System

## Overview
Developed a Course Management System using C# Console Application as part of the HCL Training Program. The project focuses on managing course-related information through a console-based application.

## Technologies Used
- C#
- .NET Console Application

## Concepts Covered
- C# Fundamentals
- Object-Oriented Programming (OOP)
- Classes and Objects
- Properties and Methods
- Collections
- Conditional Statements
- Loops
- User Input Handling
- Menu-Driven Programming

## Project Description
Created a console-based Course Management System to handle course-related operations. The application allows users to interact with the system through a menu-driven interface and perform course management activities.

## Learning Outcomes
- Understood C# console application development.
- Practiced classes and objects.
- Improved understanding of OOP concepts.
- Learned to manage data using collections.
- Practiced implementing menu-driven applications.
- Improved problem-solving and programming skills.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio.
3. Build the project.
4. Run the console application.
5. Follow the menu options displayed in the console.
