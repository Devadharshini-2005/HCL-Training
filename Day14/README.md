# Day 14 – Training Management System

## Overview
Developed a Training Management System as part of the HCL Training Program. The project focuses on managing training-related information and understanding the basic workflow of a training management application.

## Technologies Used
- C#
- .NET Console Application

## Concepts Covered
- Object-Oriented Programming (OOP)
- Classes and Objects
- Properties and Methods
- Collections
- Conditional Statements
- Loops
- User Input Handling
- Menu-Driven Programming
- Basic Business Logic

## Project Description
Created a Training Management System to organize and manage training-related information. The application provides a structured approach to handling training activities and understanding how a training management system works.

## Learning Outcomes
- Understood the workflow of a Training Management System.
- Practiced implementing real-world business logic.
- Improved understanding of OOP concepts.
- Learned to organize and manage application data.
- Strengthened C# programming and problem-solving skills.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio.
3. Build the project.
4. Run the application.
5. Follow the available menu options.
