# Day 20 – Web API Practice

## Overview
Practiced Web API development using ASP.NET Core as part of the HCL Training Program. The task focused on understanding RESTful API concepts, creating API endpoints, handling HTTP requests, and performing database operations.

## Technologies Used
- C#
- .NET
- ASP.NET Core Web API
- SQL Server
- Swagger

## Concepts Covered
- Introduction to Web API
- RESTful API Architecture
- API Controllers
- HTTP Methods (GET, POST, PUT, DELETE)
- Routing and Endpoints
- Model Binding
- Request and Response Handling
- CRUD Operations
- HTTP Status Codes
- Dependency Injection
- Swagger API Documentation
- Exception Handling

## Description
Practiced creating RESTful Web APIs using ASP.NET Core. Implemented API endpoints to understand how clients communicate with backend applications through HTTP requests and responses. Explored CRUD operations and API testing using Swagger.

## Learning Outcomes
- Understood RESTful API fundamentals.
- Learned how to create API controllers and endpoints.
- Practiced handling HTTP requests and responses.
- Implemented CRUD operations.
- Understood routing and HTTP status codes.
- Learned to test APIs using Swagger.
- Improved backend development skills.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the database connection string if required.
5. Build and run the application.
6. Open Swagger to test the API endpoints.
