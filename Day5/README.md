# Day 5 – Student Management System

## Overview
Developed a Student Management System using HTML, CSS and JavaScript as part of the HCL Training Program. The application allows users to register student details through a form and view the registered student data.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Covered
- HTML forms and input fields
- CSS styling and layouts
- JavaScript functions
- DOM manipulation
- Event handling
- Form validation
- Handling user input
- Dynamic table creation
- Displaying registered data

## Project Description
Created a Student Management System with a student registration form to collect student details. After submitting the form, the registered student information is displayed in a table. JavaScript is used to handle form submissions, validate inputs, and dynamically update the displayed data.

## Learning Outcomes
- Learned to create and handle HTML forms.
- Practiced form validation using JavaScript.
- Understood DOM manipulation.
- Learned to dynamically display data in HTML tables.
- Improved frontend development and user interaction skills.

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in any web browser.
5. Enter student details and submit the registration form.
