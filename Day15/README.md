# Day 15 – DBMS Learning and Practice

## Overview
Learned Database Management System (DBMS) concepts as part of the HCL Training Program. The task focused on understanding database fundamentals, SQL commands, and how data is stored, managed, and retrieved from relational databases.

## Topics Covered
- Introduction to DBMS
- Database and Tables
- Relational Database Concepts
- Primary Key and Foreign Key
- Constraints
- Data Types
- SQL Commands
- DDL (Data Definition Language)
- DML (Data Manipulation Language)
- DQL (Data Query Language)
- DCL (Data Control Language)
- TCL (Transaction Control Language)
- CRUD Operations
- Joins
- Aggregate Functions
- GROUP BY and ORDER BY
- Subqueries

## Description
Explored DBMS concepts and practiced SQL queries to create tables, insert records, retrieve data, update existing records, and delete records. Learned how relational databases organize information and how SQL is used to manage data efficiently.

## Learning Outcomes
- Understood database fundamentals.
- Learned relational database concepts.
- Practiced writing SQL queries.
- Understood primary keys, foreign keys, and constraints.
- Gained experience in performing CRUD operations.
- Learned how to retrieve and manipulate data using SQL.
