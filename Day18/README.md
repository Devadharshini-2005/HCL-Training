# Day 18 – E-Commerce, EF Core and Training Management

## Overview
Worked on three tasks as part of the HCL Training Program: E-Commerce Management System, Entity Framework Core Practice, and Training Management System. These tasks focused on backend development, database operations, and understanding Entity Framework Core.

## Technologies Used
- C#
- .NET
- ASP.NET Core
- Entity Framework Core
- SQL Server

## Tasks and Projects

### 1. E-Commerce Management System
Developed an E-Commerce Management System to manage product and shopping-related information. Practiced implementing backend functionality and handling application data.

### 2. EF Core Practice
Practiced Entity Framework Core to understand how .NET applications interact with databases using an Object-Relational Mapper (ORM).

**Concepts Practiced:**
- Entity Framework Core
- DbContext and DbSet
- Entity Models
- Database Configuration
- Code-First Approach
- Migrations
- Database Operations
- CRUD Operations

### 3. Training Management System
Worked on a Training Management System to manage training-related information and understand the workflow of a training management application.

## Concepts Covered
- C# Programming
- Object-Oriented Programming
- ASP.NET Core
- Entity Framework Core
- Database Connectivity
- SQL Server
- Code-First Migrations
- CRUD Operations
- Backend Development
- Data Management

## Learning Outcomes
- Gained practical experience in backend application development.
- Understood Entity Framework Core and ORM concepts.
- Learned how to configure DbContext and DbSet.
- Practiced database migrations.
- Improved understanding of database operations.
- Gained experience working on multiple management system projects.

## How to Run
1. Clone or download the repository.
2. Open the respective project folder in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the SQL Server connection string.
5. Apply database migrations if required.
6. Build and run the projects.
