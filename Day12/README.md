# Day 12 – JSON Demo in C#

## Overview
Practiced JSON (JavaScript Object Notation) handling in C# as part of the HCL Training Program. The task focused on understanding how to serialize C# objects into JSON and deserialize JSON data back into C# objects.

## Technologies Used
- C#
- .NET Console Application
- System.Text.Json

## Concepts Covered
- Introduction to JSON
- JSON Objects and Arrays
- JSON Serialization
- JSON Deserialization
- JsonSerializer Class
- Serialize() Method
- Deserialize() Method
- Working with C# Classes and Objects
- Handling JSON Data

## Description
Created a JSON demo application to understand how JSON data is handled in C#. Practiced converting C# objects into JSON strings using serialization and converting JSON strings back into C# objects using deserialization.

## Learning Outcomes
- Understood the JSON data format.
- Learned JSON serialization and deserialization.
- Practiced using the System.Text.Json namespace.
- Learned how to convert objects into JSON strings.
- Understood how to retrieve object data from JSON.
- Gained experience in handling structured data.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio.
3. Build the project.
4. Run the console application.
