# Day 22 – Movie Ticket Booking System

## Overview
Developed a complete backend for a Movie Ticket Booking System using ASP.NET Core Web API as part of the HCL Training Program. The project focuses on managing movies, theatres, screens, seats, shows, user authentication, and ticket bookings.

## Technologies Used
- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- Scalar / OpenAPI

## Key Modules
- **Authentication:** User registration and login using JWT authentication.
- **Movies:** Manage movie information.
- **Theatres:** Manage theatre details.
- **Screens:** Manage screens within theatres.
- **Seats:** Manage seat information.
- **Shows:** Manage movie show details.
- **Bookings:** Handle movie ticket booking and cancellation.

- RESTful Web API Development

- Asynchronous Programming (async/await)

## Project Description
Built a backend application for managing movie ticket booking operations. Implemented APIs for managing movies, theatres, screens, seats, shows, and bookings. Added user authentication using JWT and authorization to control access to different operations based on user roles.

## Learning Outcomes
- Gained experience in developing a complete backend application.
- Understood layered architecture and separation of responsibilities.
- Learned to implement JWT authentication.
- Practiced role-based authorization.
- Improved knowledge of Entity Framework Core and database relationships.
- Implemented asynchronous API operations.
- Learned global exception handling.
- Gained practical experience in designing and testing RESTful APIs.

## How to Run
1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the SQL Server connection string in `appsettings.json`.
5. Configure JWT settings.
6. Apply Entity Framework Core migrations.
7. Build and run the application.
8. Open the API documentation interface to test the endpoints.
