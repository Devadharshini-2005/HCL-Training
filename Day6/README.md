# Day 6 – Event Management and Coffee Brands Websites

## Overview
Developed two frontend websites, an Event Management Website and a Coffee Brands Website, using HTML, CSS and Bootstrap as part of the HCL Training Program. The task focused on creating attractive webpage layouts and understanding responsive web design using Bootstrap.

## Technologies Used
- HTML5
- CSS3
- Bootstrap

## Projects

### 1. Event Management Website
Created an Event Management Website to present event-related information with a structured and attractive layout.

### 2. Coffee Brands Website
Created a Coffee Brands Website to showcase coffee products and brand-related information using Bootstrap components and styling.

## Concepts Covered
- HTML page structure
- CSS styling
- Bootstrap grid system
- Bootstrap containers and rows
- Responsive layouts
- Bootstrap components
- Navigation bar
- Buttons and cards
- Spacing and alignment

## Learning Outcomes
- Learned how to use Bootstrap for webpage development.
- Understood the Bootstrap grid system.
- Practiced creating responsive website layouts.
- Improved webpage design and styling skills.
- Gained experience in developing multiple frontend projects.

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Locate the respective `index.html` file in each project.
4. Open it in any web browser.
