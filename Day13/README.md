# Day 13 – Hospital Appointment Management System

## Overview
Developed a Hospital Appointment Management System as part of the HCL Training Program. The project focuses on managing hospital appointments and handling patient and appointment-related information.

## Technologies Used
- C#
- .NET Console Application

## Concepts Covered
- Classes and Objects
- Object-Oriented Programming (OOP)
- Properties and Methods
- Collections
- Conditional Statements
- Loops
- User Input Handling
- Menu-Driven Programming
- Basic Business Logic

## Project Description
Created a Hospital Appointment Management System to manage patient and appointment details. The application provides a structured way to handle appointment-related operations and understand the workflow of a hospital appointment system.

## Learning Outcomes
- Understood the basic workflow of hospital appointment management.
- Practiced implementing real-world application logic.
- Improved understanding of classes and objects.
- Learned to manage patient and appointment information.
- Strengthened C# programming and problem-solving skills.
